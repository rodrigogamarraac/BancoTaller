# Banco Créditos

Proyecto React + Vite para un sistema simple de banco.

## Pruebas unitarias

Las pruebas unitarias están enfocadas en reglas de negocio, como pide la guía del EC2:

- Validación de ID de usuario antes de consultar historial crediticio.
- Búsqueda de clientes por nombre, correo o ID.
- Filtrado de pagos pendientes y ordenamiento por fecha de vencimiento.
- Evaluación de una solicitud de crédito usando puntaje crediticio y capacidad de pago.
